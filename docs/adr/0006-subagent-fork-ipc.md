# Subagent IPC: fork() + pi SDK over spawn() + JSON stdout

Subagents use `child_process.fork()` with a child script that imports `createAgentSession` from the pi SDK, forwarding all `AgentSessionEvent`s to the parent via `process.send()`. The parent sends ask responses and abort signals back via `child.send()`. One bidirectional IPC channel replaces the earlier approach of `spawn("pi", ["--mode", "json"])` plus a Unix domain socket for ask responses (two unidirectional channels). This was chosen because the SDK gives the child direct access to pi's session API (model registry, tool definitions, agent config) without re-parsing CLI args, and the single IPC channel eliminates socket lifecycle management. The trade-off is that the child must be a Node.js script (not a generic CLI process), tying subagents to the pi SDK version.
